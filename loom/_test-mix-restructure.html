Concept test — Mix & Restructure

Each Loom grid cell runs its OWN independent stippling pass (Spore's real algorithm — a hex-jittered lattice, mark size driven by local image darkness — ported to plain circles for this test, not Spore's full Genesis-mark rendering) over its own sub-region of one shared source image. "Same structure" uses identical spacing/size in every cell (only the clip shape differs); "Vary structure per cell" gives each cell its own spacing/size/rotation, proving a grid cell can be a genuinely independent generative container, not just a crop window.
