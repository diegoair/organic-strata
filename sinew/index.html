SVG paths are parsed to Bézier nodes and transformed directly (no rasterisation). Genesis forms come from the shared seed library.

Effect stack

Layers run top→bottom. In Raster, add groups that each process the shape, then composite with a blend mode (union/subtract/xor…) — overlap an outline group with a texture group for the frog-eggs look.
