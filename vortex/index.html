Format

PNG ×2/×4 is a genuine re-render at that resolution, not an upsampled bitmap — Vortex redraws from scratch every frame regardless. SVG is real vector geometry: one line per currently-visible segment, depth-correct stroke width and paint order. Both read whatever is on screen right now — pausing first is the natural way to frame a shot (camera drag still works while paused), but isn't required.
