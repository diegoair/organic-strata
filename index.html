Organica · Organic Visual System

The method of flexible visual systems, made into an instrument.

For a designer, an artist, a studio building an identity that has to live on a poster, a screen, a wall and a moving image — and stay itself.

Flexible visual systems replaced the static logo with a language: components, assets, applications. Organica takes that method one step further. The system is not described — it is built, it runs, and it composes for you.
