Foundations

Typography

One family — Manrope, variable weight 200–800 — via --font. The panel runs on exactly two styles (10/400 and 9/300); everything outside the panel uses the type scale below. No second typeface, no hardcoded font-size.

Color tokens

--ink/--paper/--panel/--mid/--border are per-tool (each tool sets its own hex in a local :root) — everything downstream reads the role, not a hex. --accent-warm and --track-bg are the two exceptions: one fixed accent, the same in every tool, so a slider or a floating toolbar reads identically regardless of which tool it's in.

Spacing

4px base grid, 8 steps. Used for gaps, padding, margins — never a raw px value that happens to look right.

If the spacing you need isn't one of these eight, that's a sign to add a step — not to reach for a raw px value.

Radius

Three steps, flat by default — Organica's surfaces are near-square, radius is a whisper. --radius-lg is reserved for the one surface that floats free of the grid (the floating toolbar); everything docked to an edge uses sm or md.

Slider

A filled housing (--track-bg) with the value up to the thumb in --accent-warm — one accent everywhere, not each tool's own hue, the same way Figma's own inspector uses one blue for every handle regardless of file content. --fill is written live by Organica.enhanceSliders(), on drag and on any script assignment to .value (so presets stay honest too).

Floating toolbar

Fixed bottom-centre over the canvas, not the browser viewport — offset by half the panel's width so it centres on the visible working area. Content is per-tool (icon buttons in whatever combination that tool needs); the shell, icon sizing and states are shared.

Defined inshared/organica-floatbar.cssUsed inStrataSporePollenHalideKomorebiLiving PathGenesis Creator
<div class="org-floatbar" role="toolbar" aria-label="Actions">
  <button class="org-floatbar__btn" aria-label="Open">…svg…</button>
  <div class="org-floatbar__sep"></div>
  <button class="org-floatbar__btn org-floatbar__btn--primary">…</button>
</div>

Centring formula: left: calc(50% - var(--panel-w, var(--panel-width-right, 248px)) / 2) — the nested fallback covers Genesis Creator, which names its panel width variable differently.

Popover

Handles the accessibility contract a bare click handler always forgets: aria-expanded, Escape to dismiss, click-outside to dismiss, focus return. Anchors upward when it lives inside the floating toolbar (the trigger sits at the bottom of the screen).

Utilities

Spacing & layout utilities

An audit found the same handful of spacing values — 6/8/10/12/14px — repeated as one-off style="margin-top:Npx" attributes, dozens of times across the suite. These classes are that token spent as a class instead of retyped as a raw number: the class name is the token index. They carry !important on purpose — a utility only does its job if it always wins the cascade, and a panel row's own class (.row .val) already outranks a single class without it.

Defined inshared/organica-tokens.css
.mt-1 … .mt-8   /* margin-top: var(--space-1…8) */
.mb-1 … .mb-8   /* margin-bottom: var(--space-1…8) */
.u-flex1        /* flex: 1 1 auto; min-width: 0 */
.u-hidden       /* display: none — only for elements NEVER
                   toggled via el.style.display in JS; toggled rows must
                   keep style="display:none" so clearing it works */
