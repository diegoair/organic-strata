    00How the variables tie together

    Every step drawn three ways from the same links, read from the code. Flow — what you set → what FVS decides → what you get; Matrix — cause in rows, effect in columns; Ring — the variables on a ring, after the “precedent models for visual systems” diagrams (Bertin, Dondis, Leborg, Van Nes, as redrawn in Lorenz 2016). Each variable has a code: its column’s letter and colour — A you set · B FVS decides · C you get. In Flow, a worked example runs through the diagram: each variable on its path shows its value and a picture of the state at that point, from the input on the left to the generated output on the right (the bold line).

    Fixed — built into FVS; you can’t change it (gates, caps, order of operations) Can be fixed — a control sets or locks it (Lock, Seed, Snap, a switch) Shapes — one feeds the other’s result

    01Element

    The panel has three sections — Layers, Shape (with Split inside) and Look & place — plus the Cell shape buttons in the floatbar. Nothing here is random except Irregularity’s seed and Blob’s seed.

    Cell shape

    Floatbar, shown on Element and Component. The cell the Element is drawn for; it sets the turn step every later rule uses. On a non-square cell every shape is fitted whole inside the outline, except Arc on a triangle (a 60° slice) and Arc truchet on a hexagon (bands round alternate corners).

    Shape

    Picker #sel-seed-type. Each shape lists its rows in one order: Type preset → proportions → Rounding / Rounding style / Edge curvature → own details → repeats. A row that would change nothing stays hidden until it would.

    ShapeType presetsControls (range · default)

    Not in the picker: custom (an uploaded SVG, a Genesis seed or a Split piece — every visible shape united, strokes outlined), stack (the layered Element), freehandraw.

    Split

    Inside the Shape section. A real geometric cut at the shape’s own box centre; the quadrants kept become one Custom shape.

    All · TL · TR · BL · BR seg-split-quadrant

    Multi‑select. All, or all four, restores the original. With layers it cuts the whole stack into one shape. Save piece as Seed… appears while a piece is cut; Show cut grid draws the cut.

    Look & place

    Applied in this order: Width / Length → Irregularity → Cut out → Copies → Scale / Move / Rotate. With layers, the first five live in each layer’s card; Scale, Move, Rotate and Fit stay here for the whole Element.

    Pattern (the Element’s)

    Shown when any layer uses Style = Pattern or the Pattern role. One set for the whole Element. Real vector paths clipped to the shape, laid out in the Element’s 0–100 box from its centre, so they turn with the cell later.

    Layers & roles

    “+” adds a layer on top (a Circle, or a Triangle if the current one is a Circle, at Size 0.6). The role icon cycles Filled → Subtraction mask → Mask → Pattern; a role acts only on the layers below it. Each layer has X / Y / Size / Rot and an ink: Follow cell colour or a fixed Ink n.

    ∞Palette & Paper

    One section under every step. Colours are plain hex: a palette is a source, never a link, so saved work never changes on its own. The order of the inks is their role (Base, Secondary, Accent…).

    Inks

    1 to 8 chips. “+” adds #888888. Pick from a palette adds one colour, or all of a palette’s colours (≤ 8).

    Sources of “Pick from a palette”

    Your TuneSutra palettes · three built‑in combinations — Violet 06, Stimulating, Violet 07 (Base / Secondary / Accent) · Riso standard inks (21, approximate).

    Colour by

    Which ink each cell gets: ink = colors[(f(cell) + Start at) mod n]. Shown on a 5×5 grid with the three inks of Stimulating, Start at = Colour 1.

    Paper

    The ground of every step, thumbnail and export. The checkerboard button makes it transparent everywhere (fill="none" in SVG, alpha in PNG). The Pattern icon lays a texture over it across the whole canvas, in one ink, in 1/100 of the canvas’s short side.

    Element (tile): Layout × Turn

    Paper pattern = Element (tile) repeats a shape in ONE ink. The tile is the Current Element, a Saved Element or a Genesis seed. Size = % of Spacing. Capped at 2,500 tiles (Spacing is raised, with a note).

    02Component

    The Element in a 1–4 × 1–4 grid (or a cell‑shape lattice). Generate runs the rule and lists every structurally distinct candidate; nothing is hidden except the exact duplicate “flip H + flip V = 180°”.

    Grid

    Transform axes

    Which values Checkerboard, Random and Exhaustive may combine — and they widen the named rules (Scale multiplies every rule’s list by 3). An axis that is off collapses to one value.

    Rotation chk-axis-rotation · on

    0 / 90 / 180 / 270° (on other cells, multiples of the shape’s own step).

    Flip chk-axis-flip

    None / H / V / both. H+V is folded into a 180° turn, never listed twice.

    Scale chk-axis-scale

    Small / Medium / Large.

    Small 10–400 · 75%Medium 100%Large 125%

    Rules

    Each card: the 2×2 candidates (up to 8) and the first 4×4 candidate, with Rotation on only. The number is how many distinct candidates Generate lists with those settings.

    Rules by grid size

    The same rule reads each cell’s column and row, so it changes with the grid. Count = distinct candidates with Rotation on (Rotation + Flip in brackets where it differs); “—” = greyed out in the menu, hover for the reason. Columns × rows, as in the panel.

    Families (what Random and Exhaustive draw from)

    Random picks a family, then one of its parameter sets, until it has Count distinct candidates (never per‑cell noise). Exhaustive lists every set of every active family, deduplicated; above 512 Generate is disabled and the hint gives the exact count.

    Rules on non‑square cells

    Only five rules run on a circle / triangle / hexagon lattice; the others grey out (“… needs a square cell”). Every turn is a multiple of the shape’s step, added to each cell’s own pose.

    Identity

    One uniform candidate per state (steps × the shape’s flips × scales).

    Radial

    Each cell turned towards the lattice centre; on triangles the Arc’s pivot corner goes to the nearest corner. One candidate per extra step × scales.

    Checkerboard

    States A / B by where the cell sits: up / down on triangles; a true checkerboard on square‑packed circles; on hex‑packed cells (every hexagon grid, packed circles) alternating lines of cells — no 2‑state pattern can make all six neighbours differ, so each cell differs from 4 of its 6.

    Random

    Each cell picks a state on its own — per‑cell noise here, unlike square cells.

    Exhaustive

    Identity ∪ Radial ∪ Checkerboard, deduplicated.

    Layer colour variants

    Shown only for a layered Element, on by default. Every candidate is repeated for every combination of layer inks: each Fill layer takes Follow cell colour or one of the palette inks → (inks + 1)layers (2 layers × 3 inks = 16). Above 512 the first 512 are shown with a note. Picking a variant makes its inks the Element’s own.

    Colourways of the selection

    Colour variants of the selected Component from the palette’s mains and their 0–900 shade scales. Every result is solved: an ink under 3:1 on its paper moves along its own scale (hue kept) until it reaches 3:1; inks closer than ΔE 6 are pushed apart; a scheme that cannot be solved is dropped. Ranked by 0.5·contrast + 0.3·ΔE + 0.2·lightness spread; “Current” first, then up to 11.

    Role

    Blend sel-component-blend

    Normal — the later cell covers the earlier. Multiply — where cells’ inks overlap (Scale > 1) they mix, and multiply with the Paper too.

    Role sel-component-role

    Normal · Container — another saved Component, clipped to this one’s cells · Mask — this one’s cells knocked out of the other and its paper. Square cells only; forces a square frame.

    Starter gallery

    Before any Generate: the first 4 of Checkerboard, Pinwheel, Mirror and Radial (if eligible) — 16 on a 2×2. On a lattice: Radial, Checkerboard, Identity. Rebuilt live while untouched.

    03Symbol

    A page (Canvas), a grid generated inside its margin, and content in each cell — saved Components (the pool: the 8 most recently saved), the Element in one of its turns, or Empty. Fill the grid runs Suggest or Arrange on an empty grid only; it never overwrites a composition.

    Canvas

    Format

    Square 1:1 · Portrait 4:5 · Landscape 16:9 · Vertical 9:16 · Widescreen 3:2 · A4 portrait / landscape · A3 portrait · Letter portrait · Custom.

    Screen / Print

    Print adds Unit (mm / in), DPI 72–2400 (300) and Bleed 0–20 mm (3). Export follows: SVG at physical size with bleed + crop marks, PNG with its DPI.

    Margin

    0–25 % of the short side (5). While every cell is empty, any change rebuilds the grid live.

    Grid generators

    Loom’s own generators, run inside the canvas margin with gap 0 so cells meet (drawn here at Loom’s defaults, gap 0). Rectangular grids show drag handles on inner borders; dragging trades size between two tracks.

    Overlap & blend

    Overlap 0–100 %

    Each cell’s content grows past its cell by ×(1 + %). Components aligned on a shared cell lattice grow that lattice instead. Above 0, Clip to cell turns off.

    Blend

    Paper under (default) — every Paper first, all inks on top · Normal — each content’s Paper right under its own ink · Multiply — no Paper, inks multiply · Shared cells — a small cell covered by two aligned Components is drawn once.

    Drawn by Shared cells only

    Who draws a shared small cell: Nearest centre · Alternate · First · Last.

    Fill modes

    Suggest suggest · default

    Proposes whole Symbols from the pool, scored (see below). The best is placed at once; the rest are in Variations.

    Arrange (pool) generate

    Places the pool by a class rule: the n‑th class takes the n‑th pool entry. Fit Stretch / Contain / Cover / Match cell. Locked cells stay; down triangles get 180°.

    Rule rule

    Changes transforms only — never content (except Orientation) — on the axes ticked in Vary. Live; lock‑aware; Reset & apply to all ignores locks.

    Manual manual

    Select cells (click, drag, ⌘‑click), then set Content, Rotation, Flip, Fit, Scale, Padding, Colour, Lock.

    Arrange rules

    Shown on a 6×6 grid with a pool of three Components A · B · C. Checkerboard uses only the first two; Random draws by weight (equal weights, seed 1).

    Rule mode

    Shown on a 6×6 grid at default settings, Vary = Rotation. Radial and Wave are drawn with “Snap to 90°” on (the default).

    Vary Rotation · Flip · ScaleScale range 20–100 (75) · 100–300 (125)Seed 0–999999 (1)

    Suggest — how it scores

    Each Component is rasterised once into an ink mask; every shared border gets 10 sample points nudged into each side. A variation = per cell {Component, turn} (8 turns/flips for a square Component in a near‑square cell, otherwise 0°/180° ± flip).

    Continuity 0–100 · 60

    Both sides of every shared border agree: ink meets ink counts most, paper meets paper a little, a mismatch costs. Same ink counts fully, distinct inks half, inks under ΔE 6 count as a seam.

    Balance 0–100 · 30

    Ink spread evenly over a 3×3 split of the page, and each Component used as often as its weight.

    Surprise 0–100 · 30

    1 − identical neighbour pairs / all pairs.

    Colour 0–100 · 40

    Only with ≥ 2 inks in the pool: a clear hierarchy against the role shares 51 / 31 / 18…, each ink spread, neighbouring inks distinct.

    Generators

    Every Arrange rule (not Random) with turns refined for continuity · 3 beam searches (width 4) over Component × turn · 2 weighted mixes. Ranked, look‑alikes dropped, top 12.

    More like this · Recolour cells (test)

    More like this: 11 variants, each re‑drawing 8–20 % of the free cells. Recolour: a cell may also take one of up to 3 colourways of its Component (same ink count and colour rule).

    04Figure

    Since Oct 2026 a Figure is made on a node graph (the Figure step’s board): Input — a Canvas, a Grid, a Palette and saved content — → Transformation — rule nodes and a Composition — → Output — Figure nodes, each with its variations, and an Export node. Nodes are shared: one Canvas can feed five Figures, each with its own Grid and Palette. A Figure compiles to the same recipe v2 as before ({tool:'fvs-recipe', version:2, element, levels, transform}), drawn by the pure evalFigure; the 25 built‑ins open as graphs and draw byte‑identically.

    Nodes

    Foundation · Canvas

    Format preset, Screen / Print, unit mm / in, size, DPI (300), bleed (3), margin (5). Decides Screen or Print for every export of the Figures it feeds.

    Foundation · Grid

    One list: Loom’s generators (Rectangular, Hexagonal, Triangular, Bento, Circular … with their own params and seed) and three lattices — Triangle rows 1–8 · Square 1–12 × 1–12 · Hexagon rings 1–6.

    Foundation · Palette

    Inks (from the palette library or by hand) + Paper + a colour rule. Optional: without one a Figure keeps its content’s own inks. Components follow it through their colourway unless Keep own colours.

    Content

    Element · Component — from the saved libraries only, each node keeps a copy so a deleted entry still draws. Set — a saved list of entries; a Figure fed a Set shows one group of variations per item (cap 24 drawn).

    Rules

    Cell rules (the class rules below) · Component rule (poses a Square lattice up to 4 × 4 by a Component family) · Repeat in grid (Square 2–6, Tier 1–3, Triangle 2–4; alternate flip; each finished figure becomes the next level’s tile) · Rotate & mirror (needs a Repeat before it) · Composition (see Compose).

    Output · Figure

    Needs a Canvas, a Grid and content (a Canvas or Grid can’t be deleted while it is a Figure’s only one). Fit, clip, Keep own colours, Variations (4 by default), Vary by, Keep, seed, Pin. Export takes Figures and writes the files.

    Cell rules

    Each rule is {when, do}; rules run in order, and the later match wins field by field. A switched‑off rule stays in the recipe. Compose adds at (cells by grid address) — see below.

    when — slot classes

    class up / down (triangles) · row · col · index · parity odd / even of col + row · ring, sector (hexagons). All present keys must match; arrays mean “any of” (not for parity). {} = every cell.

    do — actions

    content empty / filled · rotate n° (snapped to 30°) or sector (60° × the cell’s sector) · flipH · flipV · scale · seed (a different shape, JSON only).

    Built‑in figures (New figure…)

    Variations

    A Figure shows itself as set up plus its variations, drawn from its seed. Vary by: Random seed (the Grid’s own seed; how several contents spread) · One change · Several changes (2–3). Keep Content / Palette / Cell rules / Grid / Rotate & mirror holds a group still. Pin keeps a variation through a reroll and upstream edits; New Figure from this makes a sibling Figure with that variation fixed.

    GroupChangeHow it decides

    Compose

    Double‑click a Figure (or Compose…): its own cells on a sheet. Select cells — click, Shift / ⌘‑click, or a tool: Row · Column · Similar cells · Range (a rows × columns box) — then pick what they get, or drop a saved item on a cell. Every action is a region rule on the Figure’s Composition node (created with the first rule), so it reaches every variation and survives upstream changes.

    when

    The Cell‑rule keys plus at [[row, col], …] — clicked cells by grid address, so “row 2, column 3” stays that cell when the Grid gains columns. A rule naming cells the grid no longer has is kept, not drawn, and reported with its number.

    do

    The Cell‑rule actions plus content (a saved Element / Component, Palette colours unless kept) · toggle · color (a Palette ink) · symbolRule (a Symbol‑step rule over the region, its own seed, reading each cell’s place in the whole grid) · arrange (the Figure’s content by an Arrange class) · pattern (Lines / Crosshatch / Dots / Concentric).

    Checks

    Read from the drawn result: numbers valid · every clip reference resolves · defs / metadata once · slot count · shapes drawn = filled slots × tiles × mirror copies · file size · inks read on the paper (≥ 3:1) · inks distinct · mirror symmetry (> 97 %) · figure box · with a reference image: silhouette overlap (IoU > 0.8) and proportions.

    ⤓Export options that change the output

    FVS’s export popover (Element / Component / Symbol) and, for Figures, the Export node: Variations all / pinned only / as set up only · SVG · PNG ×1 / ×2 / ×4 · Plates · Transparent paper · Send to Figma; a Figure on a Print Canvas exports at its own size and DPI with bleed and crop marks.

    Screen / Print

    Screen: Scale ×1 / ×2 / ×4. Print: physical size, DPI and bleed, crop marks, DPI written into the PNG.

    Variants

    One row per variant — Fill or Stroke, one ink, a paper, stroke width 1–20 — every non‑paper colour recoloured to that ink. SVG or PNG, transparent paper option.

    Plates

    With ≥ 2 inks: one file per ink, that ink in black, the others removed, no paper. Print adds crop and registration marks.
