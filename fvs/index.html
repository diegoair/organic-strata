Palette

Ink — colours cycle across the grid's own cells by index (cell 1 → colour 1, cell 2 → colour 2, wrapping if there are more cells than colours). One colour by default (a plain fill); add more for a genuinely multi-colour grid.

Named rules (Identity/Pinwheel/Mirror/Diagonal/Checkerboard) use their own fixed pattern and ignore these. Random and Exhaustive instead pick from a small library of symmetric arrangements built from these same rules — active axes gate which arrangements are eligible (Pinwheel/Diagonal need Rotation, Mirror needs Flip, Checkerboard needs any one) and how much each varies. Every result is still a real symmetry, never 4 independently-chosen cells — that's deliberate, it's what keeps Random/Exhaustive from looking like noise.
