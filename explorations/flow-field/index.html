Loads a Loom (/loom/) JSON export and uses ITS cells — rect or any polygon shape (Hexagonal, Voronoi, Radial, Triangular, Diamond, Circular…) — as the flow field's own grid, instead of uniform squares. Each Loom cell gets one coherent-noise angle sampled at its own centroid, so every particle inside that cell drifts together; Cell size below becomes the RESOLUTION at which a point is resolved to its containing Loom cell, not the flow cell itself.
