Membrane

Organica exploration — ported from generative-design's P_2_2_3_02 ("form morphing process by connected random agents", Groß/Bohnacker/Laub/Lazzeroni, Generative Gestaltung, Apache 2.0). A ring of points each takes its own small independent random step every frame; drawn as one smooth curve through all of them, on a canvas that's never cleared, the accumulating strokes read as a soft membrane breathing and drifting — Organica's own "not drawn, allowed to happen" gesture, one step removed from the drop mark.

Resolution is how many points make up the form; Init radius sets the size of a freshly spawned one. Circle closes the curve into a loop; Line leaves it open, stretched between two random endpoints; Point collapses the form to a single dot — no curve, no Resolution, just one agent that still breathes with Step size and can be driven by any Movement pattern (this is the same "small dot" Write as brush already gave Follow path specifically, now available everywhere). Fill (Ink section) has no effect in Point mode, a single dot has no enclosed shape to wash a fill under.

Contour walks Resolution rays outward from the image's own weighted centroid and stops each one at the last dark (or, inverted, light) pixel — the ring of points traces the subject's silhouette. Luminance scatter instead samples Resolution points at random, weighted toward dark areas, then sorts them by angle around their own centroid so the connected curve still reads as one coherent loop instead of a scribble. Once an Image source is active, clicking the canvas (or Reseed) re-samples — deterministic for Contour, freshly random for Scatter. Text instead samples the REAL glyph outline of the typed Word (a vendored font, not a raster guess) — Seed style/Threshold/Invert don't apply to it.

Step size is how far each point can wander in one frame — small values breathe gently, large values tear the form apart into chaos. Movement pattern is what drives the whole form's own centre: Float to mouse (original behaviour) eases toward the pointer; the rest are fixed, predictable trajectories independent of the mouse — Linear bounces off the canvas edges like a ball, Orbit circles the centre, Zigzag bounces along a diagonal, Figure-8 and Sine drift trace their own named curves, Follow path walks an ordered sequence of waypoints start to end and loops. Path source picks where those waypoints come from: Text outline re-traces the last Text seed's own dense glyph outline (needs Seed source set to Text at least once first); Loom grid instead walks a JSON grid exported from /loom/, cell centroid to cell centroid or vertex to vertex along each cell's own border (Loom path style), in the cells' own Number order (Sequential/Shuffle) — same file format Flow Field's own Loom-grid loader reads. Draw full path draws the WHOLE path immediately as one clean static line, breaks skipped, regardless of Step size/Move speed/Draw mode — the direct fix for Line/Circle at real speed just smearing a fresh shape onto a new position every frame instead of tracing cleanly; Write as brush additionally shrinks the form to a small dot that visibly travels the path on top of that static line — re-seeding reproduces both every time instead of needing a one-off manual fix. Click anywhere on the canvas to spawn a fresh form at that point (Movement then keeps driving it from there).

Single ink is the original one-colour stroke, and the only mode Fill applies to (a per-segment stroke has no single enclosed shape to wash a fill under). Rainbow gives each of the curve's own segments a fixed hue by position, cycling the full spectrum once around the form. Sample from image reads each segment's own colour live from the loaded image, at whatever position that segment currently drifts to — needs an Image seed loaded above.
